# 🔗 URL Shortener

A simple and efficient URL Shortener built using **Node.js**, **Express.js**, **MongoDB**, and **EJS**.

## 🚀 Live Demo

👉 **Live Website:** https://url-shortner-git-main-ashutoshsingh202003-4391s-projects.vercel.app/

---

## 📸 Preview

Paste a long URL and generate a shortened version instantly.

Example:

Long URL

https://www.google.com/search?q=nodejs

↓

Short URL

https://YOUR-VERCEL-LINK.vercel.app/abc123

---

## ✨ Features

- Shorten long URLs
- Redirect to original URLs
- MongoDB database integration
- Unique short codes using ShortID
- Responsive UI
- Clean and simple design
- Deployed on Vercel
